## How to Use

### First Time Setup
1. Sign up with your email and select your role (Super Admin recommended for full access)
2. Log in to access the dashboard

### Managing Employees
- Navigate to "Employees" → Use filters/search → Export if needed
- Click "Invite" button in header to add new users

### Creating Projects
- Go to "Projects" → Click "New Project" → Fill form → Create

### Processing Payroll
- Navigate to "Payroll" → Select month/year → View records

### Tracking Attendance
- Go to "Attendance" → Click "Check In" to start day → "Check Out" to end day

### Messaging
- Click "Messages" in sidebar → Select conversation → Send message

## Role Permissions

- **Super Admin**: Full system access
- **Admin**: Employee & Payroll management
- **HR Manager**: HR functions, payroll, employee management
- **Manager**: Team management, project assignment
- **Employee**: View own data, check-in/out
